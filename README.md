# FolkApps

## Asset register prototype

Open [asset-register-prototype.html](./asset-register-prototype.html) in a modern browser to explore the responsive asset register UI prototype. It contains 30 interactive screens, including the India/state/centre map, active centre directory, six-month verification cycle with a two-month scan window, missing-asset escalation, and damage/repair reporting.

The map boundary layer and icon library load from public internet sources. Centre locations without a verified building address are shown at city level and marked for confirmation by the centre head.
